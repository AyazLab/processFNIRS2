# Citing processFNIRS2

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23348858.svg)](https://doi.org/10.5281/zenodo.23348858)

If you use processFNIRS2 in your research, please cite the software. Each
release is archived on [Zenodo](https://doi.org/10.5281/zenodo.23348858).

## Which DOI to use

| DOI | Points to | Use it for |
|-----|-----------|------------|
| [10.5281/zenodo.23348858](https://doi.org/10.5281/zenodo.23348858) | processFNIRS2 as a whole; always resolves to the latest release | Citing the toolbox in general |
| Version DOI, listed on the [Zenodo record](https://doi.org/10.5281/zenodo.23348858) under "Versions" | One specific release | Methods sections and code-availability statements, so readers can reproduce your analysis |

Check the version you ran with `pf2_base.pf2version()`. For v1.2.0 the version
DOI is [10.5281/zenodo.23348859](https://doi.org/10.5281/zenodo.23348859).

## APA

> Curtin, A., & Ayaz, H. (2026). *processFNIRS2* (Version v1.2.1) [Computer
> software]. Zenodo. https://doi.org/10.5281/zenodo.23348858

## BibTeX

```bibtex
@software{curtin2026processfnirs2,
  author    = {Curtin, Adrian and Ayaz, Hasan},
  title     = {processFNIRS2},
  version   = {v1.2.1},
  publisher = {Zenodo},
  year      = {2026},
  doi       = {10.5281/zenodo.23348858},
  url       = {https://doi.org/10.5281/zenodo.23348858},
  license   = {GPL-3.0-or-later}
}
```

For a specific release, replace the `doi`, `url` and `version` with that
release's values from Zenodo.

## Other formats

- **GitHub:** the "Cite this repository" button on the
  [repository page](https://github.com/AyazLab/processFNIRS2) exports APA and
  BibTeX from
  [`CITATION.cff`](https://github.com/AyazLab/processFNIRS2/blob/master/CITATION.cff).
- **Zenodo:** the record's "Citation" box offers further styles and export
  formats (RIS, CSL JSON, DataCite XML).

A companion publication will be listed here when available.
